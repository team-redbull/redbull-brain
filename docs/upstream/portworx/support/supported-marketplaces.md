# Portworx Releases on Supported Marketplaces

Source: https://docs.portworx.com/portworx-enterprise/support/supported-marketplaces (Portworx Enterprise latest)

Portworx Releases on Supported Marketplaces | Portworx Enterprise Documentation

This topic lists the official Portworx releases available on supported marketplaces. It provides the most up-to-date information on certified versions that are publicly accessible for marketplace deployments.

note

Marketplace availability might differ from general availability (GA) releases. Each build must pass marketplace-specific qualification before listing. Check this topic before planning production upgrades or new deployments through a marketplace.

## Portworx Enterprise Supported Marketplaces​

Portworx Enterprise actively qualifies and publishes releases to the following marketplaces:

- IBM Cloud Catalog

- Microsoft Azure Marketplace

- AWS Marketplace

- Google Cloud Platform Marketplace

- SUSE Rancher Marketplace
