Everpure Cloud Dedicated, is a storage solution from Everpure that delivers enterprise-grade block storage capabilities within both Microsoft Azure and Amazon Web Services (AWS). It enables consistent operations and seamless workload mobility across AWS and Azure environments.

Key features include:

- Data mobility for disaster recovery and migration

- Enterprise-grade data services such as data reduction and snapshots

- High availability across availability zones

- Thin provisioning and cost optimization

Everpure Cloud Dedicated uses FlashArray technology to provide low latency, high performance, and robust fault tolerance, matching the reliability of on-premises FlashArrays.

For more information, see the Everpure Cloud Dedicated documentation.

## Install Everpure Cloud Dedicated​

Portworx Enterprise supports deploying Everpure Cloud Dedicated on both Amazon Web Services (AWS) and Microsoft Azure. To deploy Everpure Cloud Dedicated, refer to the following documentation:

- Everpure Cloud Dedicated for Azure

- Everpure Cloud Dedicated for AWS
