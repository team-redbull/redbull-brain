# Portworx Enterprise Support Matrix

Source: https://docs.portworx.com/portworx-enterprise/support-matrix (Portworx Enterprise latest)

Portworx Enterprise Support Matrix | Portworx Enterprise Documentation

The Portworx Support Matrix helps you verify which environments, components, and versions work with Portworx Enterprise. You can use this matrix to plan, validate, and maintain supported deployments across a variety of platforms. The topics listed here provide details about supported kernels, Kubernetes versions, Purity versions, and disk types. You can also find guidance on the OpenShift Operator upgrade path and the Portworx Helm chart. Review the information provided in the following topics before installation or upgrade, to ensure that you meet all compatibility requirements and avoid configuration issues.
