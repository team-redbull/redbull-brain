`lsctl` is the license server command-line interface that allows you to control the Portworx license server independently from Portworx Central. This cli is intended for advanced operations staff which may require custom license server implementations not achievable through the Portworx Central UI and offers more options and provides more granular control of your Portworx license server than the Portworx Central UI. You may need to use `lsctl` to perform certain actions that you cannot perform from the Portworx Central UI.

If you want to install the license server and administer it manually using the command line, follow the articles below in order:

- Manually install a Portworx license server

- (Recommended) Install a backup license server

- Add licenses to a license server using `lsctl`
